# Broadwater AI Co.

Static four-page website for a Gold Coast AI implementation company, published on GitHub Pages.

**Working name:** Broadwater AI Co.

This name is a placeholder. It was chosen because it is plainly local (the Gold Coast Broadwater) and, at the time of launch, was not an obvious existing AI business. “Gold Coast AI Co.” was avoided — a US firm already trades as Gold Coast AI / Gold Coast AI Automations (goldcoastai.pro).

To rename: find-replace the exact string `Broadwater AI Co.` across the repo. The name is also recorded in `SITE_NAME.txt`, in `js/contact.js`, and as `--site-name` in `css/styles.css`.

## Design

Warm, local and practical. Colour and type are original. The tone takes cues from Gold Coast businesses Damien mentioned (Big Burjos Marine, ASW Marine, Fur Baby Hampers) without copying their logos, names or brand assets. The wordmark is text only.

- **Colours:** sand `#F3EDE3`, paper `#FFFBF5`, ink `#241C16`, sea `#2C554E`, sea-deep `#1C3A36`, clay `#C45C2A`, sage `#DDE3CC`, drift `#C9B8A0`
- **Type:** Fraunces (headings and wordmark), Source Sans 3 (body), self-hosted

Photographs are of the Gold Coast Broadwater, by Kgbo, Wikimedia Commons, CC BY-SA 4.0. See `images/CREDITS.txt`.

## Deploy

This is a static site. GitHub Pages is served from the `main` branch, root (`/`). Do not deploy into `dm-hq`.
